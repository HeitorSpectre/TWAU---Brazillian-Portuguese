# The Wolf Among Us — Brazilian Portuguese Translation

**[English](#english)** · **[Português](#português)**

## English

This is a Brazilian Portuguese translation of **The Wolf Among Us Remastered**, released on October 29, 2026.

It is a complete translation, based entirely on the *Fables* comics. The names of characters, places and terms follow the Brazilian editions of the comics, and you can check every one of them in the **[name glossary](Glossary/Glossary.md)**.

The translation was made entirely by humans, with no generative AI used in the translation itself.

### About this repository

This repository holds the translation in simple, readable formats, so anyone can read it. It is basically an open-source version of the translation:

- what were DDS textures are now **PNG** images;
- what were Telltale's own binary text files (`.landb`) are now **CSV** files;
- the other texts (scripts, properties and scenes) are now plain text files.

Every part has an English and a Portuguese version side by side.

| Folder | Contents |
|---|---|
| [`Text`](Text) | Game texts (dialogue, menus, Fablespedia, achievements) as CSV, by episode, Menu, Boot and Project |
| [`Textures`](Textures) | Translated textures as PNG, by episode and Menu |
| [`Scripts`](Scripts) | Boot script (`bootTitle.lua`) with the legal notice |
| [`Properties`](Properties) | End-of-episode choice summaries (`choice.prop`, `stats.prop`) |
| [`Scenes`](Scenes) | Texts stored inside scenes (`ui_menu_list_stat_end.scene`) |
| [`Glossary`](Glossary/Glossary.md) | Name glossary, with the first appearance of each name in the US and Brazilian editions |

## Português

Esta é uma tradução para português do Brasil do **The Wolf Among Us Remastered**, lançado em 29 de outubro de 2026.

É uma tradução completa, baseada inteiramente nos quadrinhos de *Fábulas*. Os nomes de personagens, lugares e termos seguem as edições brasileiras dos quadrinhos, e você pode conferir todos eles no **[glossário de nomes](Glossary/Glossary.md)**.

A tradução foi feita totalmente por humanos, sem uso de IA generativa na parte da tradução.

### Sobre este repositório

Este repositório guarda a tradução em formatos simples, para que qualquer pessoa possa ler. É basicamente uma versão open source da tradução:

- o que eram texturas DDS virou imagem **PNG**;
- o que eram arquivos de texto em binário próprio da Telltale (`.landb`) virou arquivo **CSV**;
- os outros textos (scripts, propriedades e cenas) viraram arquivos de texto simples.

Cada parte tem a versão em inglês e a versão em português lado a lado.

| Pasta | Conteúdo |
|---|---|
| [`Text`](Text) | Textos do jogo (diálogos, menus, Fablespédia, conquistas) em CSV, por episódio, Menu, Boot e Project |
| [`Textures`](Textures) | Texturas traduzidas em PNG, por episódio e Menu |
| [`Scripts`](Scripts) | Script do boot (`bootTitle.lua`) com o aviso legal |
| [`Properties`](Properties) | Resumos de escolhas do fim de episódio (`choice.prop`, `stats.prop`) |
| [`Scenes`](Scenes) | Textos guardados dentro de cenas (`ui_menu_list_stat_end.scene`) |
| [`Glossary`](Glossary/Glossary.md) | Glossário de nomes, com a primeira aparição de cada nome nas edições americana e brasileira |
